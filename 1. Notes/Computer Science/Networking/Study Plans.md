### ✅ Level 1: **Essential Building Blocks**

| RFC     | Title    | Why It Matters                                   |
| ------- | -------- | ------------------------------------------------ |
| RFC 791 | **IPv4** | Defines how IP packets are formed and routed     |
| RFC 792 | **ICMP** | Used in `ping`, traceroute, and error reporting  |
| RFC 768 | **UDP**  | Simple, connectionless transport                 |
| RFC 793 | **TCP**  | Core of reliable, connection-based communication |
### ✅ Level 2: **Addressing and Names**

| RFC                 | Title                       | Why It Matters                   |
| ------------------- | --------------------------- | -------------------------------- |
| RFC 1034 / RFC 1035 | **DNS**                     | How domain name resolution works |
| RFC 1918            | **Private IPv4 Addressing** | Explains 192.168.x.x, etc.       |
| RFC 4291            | **IPv6 Addressing**         | Core concept of IPv6             |

### ✅ Level 3: **Protocols You'll Use Everyday**

| RFC                     | Title        | Why It Matters                    |
| ----------------------- | ------------ | --------------------------------- |
| RFC 2616 (or RFC 7230+) | **HTTP/1.1** | How web requests/responses work   |
| RFC 5246                | **TLS 1.2**  | Foundation of HTTPS security      |
| RFC 2131                | **DHCP**     | How devices get IPs automatically |

### ✅ Level 4: **Sockets and NAT**
